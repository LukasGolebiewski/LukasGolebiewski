### About

Before software I spent several years in industrial B2B — measurement and instrumentation (pressure, temperature, transducers, data loggers). That's why I start from the process rather than the tool: I'm more interested in **what is actually worth automating** than in which platform does it.

I also come from a testing background, which means I test and monitor what I build instead of shipping and hoping.
